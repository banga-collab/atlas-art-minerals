                                Importer vos produits depuis Excel, avec les photos

                                Fichier .xlsx (recommandé), .xls ou .csv. Les en-têtes sur deux lignes (ex. Product (cm) › Length) et les cellules fusionnées sont reconnus. Les lignes qui ont le même Nº (ou le même nom) deviennent un seul produit avec plusieurs tailles (S, M, L…), chacune avec sa référence, son poids, ses dimensions et son emballage.

                                Photos : les images collées dans le fichier Excel sont récupérées automatiquement (une par ligne). Sinon, les liens des colonnes Webp / Jpeg sont téléchargés (Google Drive ou Dropbox : le fichier doit être partagé « tous les utilisateurs disposant du lien »). Toutes les photos sont optimisées comme les autres.
